# Reino da Bianca

Aplicativo PWA que transforma o tabuleiro físico de metas da Bianca em um jogo: mapa 2,5D com 5 regiões e 25 fases, metas diárias e especiais,
selos, moedas, recompensas, minigames e sincronização entre aparelhos (Supabase). Custo adicional R$ 0.

- Experimente sem conta: `npm install && npm run dev` → <http://localhost:5173/?demo> (dados fictícios, só neste aparelho).
